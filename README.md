## 📱 SMART HOME MOBILE APP — From Scratch to MVP

### 🚀 Project Overview

- Designed and structured a smart home mobile application for a smart device manufacturer  
- Delivered a complete analytical package and interactive MVP prototype within 4 weeks to support stakeholder validation of the Energy Saving Mode feature

---

### 👩‍💼 My Role

- Elicited and analyzed stakeholder requirements  
- Structured product scope and user flows  
- Modeled business and data processes (USM, DFD, ER, ISD)  
- Prepared supporting documentation (Data Dictionary, Test Report)  
- Designed interactive prototype  
- Presented the solution and artifacts to stakeholders  

---

### ✅ Key Outcome
- MVP prototype delivered in 4 weeks
- End-to-end requirements package prepared
- Energy Saving Mode concept validated via prototype

### 🔄 Work Process

1. Conducted stakeholder interviews (client, end users, marketing) and performed requirements analysis

2. Modeled requirements using **User Stories** with acceptance criteria
- [View User Story Map](https://miro.com/app/board/uXjVJWxOVAo=/)

4. Designed data flows using **DFD (Context & Logical levels)**
- Context Diagram — [view](https://github.com/edmnikolaeva/stets_home/blob/main/DFD_контекстная_Stets_Home.jpg)
- Logical Diagram — [view](https://github.com/edmnikolaeva/stets_home/blob/main/DFD_логическая_Stets_Home.jpg)

4. Developed logical data model using **ER Diagram**
- [View ER Diagram](https://github.com/edmnikolaeva/stets_home/blob/main/ER_Stets_Home.jpg)

6. Compiled **Data Dictionary**
- [View Data Dictionary](https://github.com/edmnikolaeva/stets_home/blob/main/Словарь_данных_Stets_Home.pdf)

8. Modeled interface structure using **ISD**
- [View ISD](https://github.com/edmnikolaeva/stets_home/blob/main/ISD_Stets_Home.jpg)

10. Created **storyboards** for all application features

11. Built an **interactive prototype in Figma**
- [View Prototype](https://www.figma.com/design/qoXc85GFJbn8pPUBH3f5BV/Дизайн-система-Stets?node-id=4-581&p=f&t=8vTz1VQW3cueg6oN-0)

13. Prepared **Test Summary Report**
- [View Test Summary Report](https://github.com/edmnikolaeva/stets_home/blob/main/ПМИ_Stets_Home%20Николаева.pdf)

15. Presented the interactive prototype and full documentation package to the client
